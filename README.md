# 🌍 Temperature Prediction using Machine Learning  

This project analyzes global temperature data and predicts future temperatures using **Linear Regression**. 📈  

## 🔍 Overview  
- Uses **Pandas, Matplotlib, Seaborn, and Scikit-Learn** for data analysis and visualization.  
- Performs **data cleaning, trend analysis, and future temperature prediction**.  
- Predicts **temperature for the year 2050** based on historical trends.  

## 📂 Dataset  
- **File**: `GlobalTemperatures.csv`  
- **Source**: [Kaggle - Global Temperature Data](https://www.kaggle.com/datasets/berkeleyearth/climate-change-earth-surface-temperature-data)  
- Contains **monthly temperature records** from different parts of the world.  

## 🚀 Technologies Used  
- **Python**  
- **Pandas** (for data manipulation)  
- **Matplotlib & Seaborn** (for visualization)  
- **Scikit-Learn** (for building the Linear Regression model)  

## 📊 Key Steps  
1. **Data Loading & Preprocessing**  
   - Read and clean the dataset.  
   - Extract year-wise temperature trends.  
2. **Data Visualization**  
   - Generate **heatmaps and trend lines** to understand temperature patterns.  
3. **Linear Regression Model**  
   - Train a model to predict future temperatures.  
   - Predict **global temperature for 2050**.  
4. **Results & Conclusion**  
   - Visualize the predicted trend and discuss insights.  

## 🖼️ Visualizations  
✅ Heatmap of yearly temperature trends  
✅ Scatter plot with regression line for prediction
